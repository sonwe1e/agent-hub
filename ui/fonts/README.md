# Bundled font notices

The Latin-subset WOFF2 files are bundled for offline use:

- `newsreader-latin-400.woff2` and `newsreader-latin-600.woff2`: Newsreader; copyright and license in [OFL.txt](OFL.txt), from the [Google Fonts source](https://github.com/google/fonts/blob/main/ofl/newsreader/OFL.txt).
- `plexsans-latin-wght.woff2` and `plexmono-latin-400.woff2`: IBM Plex Sans and IBM Plex Mono; copyright and license in [OFL-IBM-Plex.txt](OFL-IBM-Plex.txt), from the [Sans](https://github.com/google/fonts/blob/main/ofl/ibmplexsans/OFL.txt) and [Mono](https://github.com/google/fonts/blob/main/ofl/ibmplexmono/OFL.txt) sources. The two upstream license files are identical.
